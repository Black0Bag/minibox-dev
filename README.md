# minibox-dev（文档仓库）

minibox 项目的文档中心。本仓库 `opencode` 分支存放从零推进（2026-08 起）的设计与任务文档。

## 分支说明

- `opencode`（默认）：本次从零推进任务的文档分支，所有新文档在此维护
- `OmniBot`：历史遗留分支，仅存档，不再维护

## 文档清单

| 文档 | 说明 |
|---|---|
| `minibox进度跟踪.md` | 项目从零推进的完整进度记录（立项→设计阶段全部决策） |
| `minibox-PRD-立项版.md` | 产品需求文档 v1.0 立项版 |
| `编码任务追踪.md` | 编码阶段（第 3 步）进度追踪，防上下文漂移 |

## 规则

- 进度文档只允许末尾按时间戳滚动追加，不删改已写入内容
- 敏感信息（API key 等）一律不上传，仅本地测试用临时配置文件调用
