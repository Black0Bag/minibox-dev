# minibox-dev

minibox 项目的精简决策与交接仓库。历史滚动日志、原始路线图、旧技术调研和重复测试报告已在 2026-08-25 收尾阶段删除，避免后续 AI 或开发者读取到过时结论。

## 当前事实

- Go 后端核心阶段已完成，并已通过全仓测试、vet、构建及 REST/SSE/WS 冒烟。
- Android 前端尚未创建源码工程，当前进入协议冻结与工程准备阶段。
- 当前 API、SSE、WebSocket 和代码库事实以 `minibox` 后端仓库 `docs/` 为准。
- 真实凭据只存在本地稳定验证配置，不进入本仓库。

## 维护规则

1. 这里只写当前结论、开放决策和交接说明，不恢复滚动流水账。
2. 实现细节优先链接到源码仓库，不复制会漂移的大段 API 定义。
3. 新决策可直接修订当前文档；需要追溯时依赖 Git 历史。
4. 不写入 API Key、Token、设备凭据、用户数据或私有服务地址。
5. 前后端契约变更必须先更新后端 `docs/`，再更新前端 DTO。
