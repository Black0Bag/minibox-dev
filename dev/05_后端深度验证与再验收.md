# minibox 后端最终验收摘要

## 最终状态

2026-08-25，后端核心修复、回归测试、构建和隔离冒烟已完成，可以进入 Android 前端工程准备。该结论取代 2026-08-24 的中间阻塞结论。

## 已完成修复

- 兼容 OpenAI 供应商在非流式请求中返回 SSE。
- 修复 Embedding URL/字段/query-passage/维度契约。
- 修复 FTS5 中文预分词索引和历史回填。
- WebSocket 改为单读循环 + pending map，支持并发乱序回执。
- SSE `Last-Event-ID` 原子订阅与历史回放。
- 知识编译接入 LLM 结构化提炼并保留失败降级。
- 18 个设备工具接入 Agent 工具系统并标注风险/审批。
- 修复团队分诊、JSON tag、调度/设备 API 等已发现问题。

## 质量证据

- `go test -count=1 ./...` 通过。
- `go vet ./...` 通过。
- 最新源码构建成功。
- REST 健康/就绪/配置/会话/知识/工具/权限/设备/调度/监控完成冒烟。
- SSE 握手与 HTTP 重连回放测试通过。

## 外部服务说明

真实 LLM 连续测试出现部分供应商 429 RPM 限流。已成功取得有效回答，失败日志明确为上游配额限制；这不等价于代码错误，也不能作为生产 SLA。

## 未覆盖边界

- 未执行真实 Android 设备副作用。

- REST 非 loopback 认证方案尚需产品决策。
