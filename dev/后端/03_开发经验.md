## 二、已踩过的坑（必须避免）

### 2.1 SSE 流式三大 Bug（v1.0.2 ~ v1.0.3）

| Bug | 根因 | 修复 |
|---|---|---|
| SSE data 字段类型不一致 | 非字符串类型直接写入 data 字段 | 统一为 string，非 string 先 JSON 序列化 |
| 流式输出不工作 | agent_loop.go 调用 Provider.Chat()（非流式） | 改为 ChatStream()，逐块推送 EventMessage 增量 |
| 工具调用拼接错误 | Delta ToolCall 分片未正确组装 | 按 DeltaToolCall.Index 用 map 拼装为完整 ToolCall |

### 2.2 版本号双重变量

**问题**：`main.go` 的 `var version`（启动横幅）和 `router.go` 的 `var Version`（API 响应）是两个独立变量，升级时只改了一个。

**教训**：新版必须统一版本号来源，只在一个地方定义，其他地方引用。

### 2.3 .gitignore 误匹配

**问题**：`.gitignore` 第 6 行 `minibox` 匹配了 `cmd/minibox/` 目录，导致 CI 构建找不到入口。

**修复**：改为 `/minibox`（只匹配根目录）。

### 2.4 二进制传输方式

| 方式 | 结果 | 原因 |
|---|---|---|
| base64 管道传输 | ❌ EOFError | 6MB 二进制过大，paramiko 缓冲区溢出 |
| SFTP sftp.put() | ✅ 成功 | 直接文件传输 |

**教训**：路由器部署用 SFTP，不用 base64 管道。

### 2.5 模式切换 405 问题

**问题**：mode 切换返回 405 Method Not Allowed。

**修复**：路由注册时确保 GET/POST 都注册。

### 2.6 procd 自启失败

**问题**：OpenWrt procd init 脚本不工作。

**替代方案**：`rc.local` + `nohup` 实现开机自启。

### 2.7 路由器端口混淆

**问题**：代码中 HTTP 端口写 8090，实际路由器服务端口是 8084。

**教训**：配置文件中的端口与文档/记忆中的端口必须一致。

## 五、sage-wiki 代码级融合经验

### 5.1 MCP SSE 绑定地址与公告地址分离（重要！）

**问题**：MCP SSE 模式 `--bind 0.0.0.0:8083` 时，SSE 握手返回的 endpoint URL 包含 `0.0.0.0`，远程客户端无法连接。

**根因**：`ServeSSE(addr string)` 中 addr 同时用于 `Start()`（监听）和 `WithBaseURL()`（公告）。

**正确方案**：分离 `listenAddr`（可传 `0.0.0.0`）和 `advertiseURL`（必须传客户端可达地址）。

**新版 minibox 注意**：MCP Streamable HTTP 模式也需分离监听地址和公告地址。

### 5.2 sage-wiki 核心包依赖链（已验证可独立提取）

```
hybrid (200行)
  ├── memory (432行)  ->  storage (433行)  ->  modernc.org/sqlite
  └── vectors (310行)  ->  storage (433行)

embed (556行)  ->  需去耦（内联 config/llm 类型）
log (75行)     ->  零依赖
```

**关键发现**：这 6 个包形成自闭合依赖环，不依赖 compiler/query/trust/ontology 等上层包。

## 九、关键约束提醒

1. **minibox-bin 文件夹**：`/workspace/minibox-bin/` 是验证环境，禁止未授权操作
2. **GitHub Token**：存储在 `.omnibot/memory/DEVICES.md` 中，用于 CI 日志下载
3. **SSH 接入策略**：优先内网（192.168.x.x），不通走外网 IPv6
4. **路由器自启**：procd 不可用，用 rc.local + nohup
5. **版本号统一**：只在一个地方定义，避免双重变量
6. **CGO_ENABLED=0**：必须纯静态编译，路由器无 C 工具链

## 十、新版 v2.0 重构要点总结

| 维度 | 旧版做法 | 新版改进 |
|---|---|---|
| 存储 | JSON 文件（原子写入） | SQLite WAL（代码级融合 sage-wiki） |
| 记忆搜索 | strings.Contains 子串 | FTS5 BM25 + 向量余弦 + RRF 融合 |
| LLM | 单 Provider + FallbackChain | 多供应商 + 多 Key 轮询 + 断路器 + 思考强度 |
| MCP | 基础 Server/Client | 保留 sage-wiki 18 个工具（中文化重命名） |
| 工具系统 | Registry + PermissionGuard | 接口模式 + 动态注册 + 插件 |
| API | 17 个端点 | 64 个端点（全功能 API 化） |
| CLI | 无 | 配置/启动/版本/升级/状态 |
| 自升级 | 手动 SFTP | GitHub Release 自动下载 + 脚本回滚 |
| 版本号 | 双变量（坑） | 单一来源 |
| Go 版本 | 1.22 | 1.25+ |
| 依赖 | chi + yaml | + modernc.org/sqlite + mcp-go + gobreaker |
