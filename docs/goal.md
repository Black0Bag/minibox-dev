# 项目总目标（Goal）

## 项目背景

minibox 由一个 Go 后端中枢和一个 Android 前端组成。后端负责 Agent、LLM、知识库、工具与调度；前端负责用户交互和设备能力。

## 总目标

在私有化、可审计和默认安全的前提下，提供可以长期维护的强 Agent 系统。

## 成功标准

- 后端协议和安全边界稳定，可被 Android 客户端可靠调用。
- 前端不复制 Agent/LLM/数据库逻辑，只实现 UI、网络和设备执行。
- 危险操作需要明确审批和审计。
- 文档只保留当前事实，不用过时流水账指导开发。

## 范围边界（做 / 不做）

- 做：产品决策、前后端边界、阶段路线、验收摘要。
- 不做：在 Dev 仓库复制源码、测试产物、凭据或完整历史日志。

## 约束条件

- 中文优先；后端 Go/SQLite/REST/SSE/WS；前端 Kotlin/Compose/Navigation 3。
- 前端不直接访问 SQLite。
- 当前真实实现以源码仓库及其 `docs/` 为准。
