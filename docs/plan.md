# 实施计划（Plan）

## 里程碑

1. 后端收尾：完成代码、测试、文档和稳定实例整理。
2. 协议冻结：确认 REST/SSE/WS DTO、认证和审批缺口。
3. Android 地基：创建 Compose + Navigation 3 工程及网络层。
4. 前端主流程：连接诊断、会话、SSE、设备代理。
5. 扩展界面：知识库、监控、调度、团队和安全管理。

## 任务拆解

- 后端：仅做前端阻塞型契约修复、安全修复和回归维护。
- Dev：维护精简结论，不恢复原始滚动文档。
- Android：按 `dev/03_前端开发路线图.md` 开发。
- 联调：优先 Mock 与模拟设备，再单独授权真实副作用。

## 验收节点

- API DTO 与后端 JSON tag 一致。
- SSE 可断线重连且按 seq 去重。
- WebSocket 可认证、心跳、并发请求和乱序回执。
- Compose UI 支持 TalkBack、48dp 触控、字体放大和深色主题。
- 危险功能不以无效或绕过审批的按钮暴露。

- 已解除：REST 认证、审批提交 API、teamwork DTO 命名（2026-09-02 全部完成
  并有测试锁定）。
- 回滚：前端分阶段提交；协议改动保持向后兼容；高风险后端操作不纳入首版 UI。
